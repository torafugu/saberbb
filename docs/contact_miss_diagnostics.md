# length / thickness missの独立診断

`sql/diagnostics/contact_miss_diagnostics.sql` の4本を実行する。
`:first_game_id` と `:last_game_id` に、現在の見送り判断で生成した試合ID範囲を指定する。
名前付きパラメータ非対応のツールなら、2つの名前を数値へ置き換える。
追加のDB移行・試合の再生成は不要。既存の記録列から計算する。
旧版と現行版の接触条件が混在する範囲は避ける。

現行の接触判定は長さ0.16m、厚み0.070mをそれぞれ「超えた」ときに空振りとする。
SQLも厳密な `>` を使い、等値は範囲内。両方を超える場合をlength_onlyへ含めない。

| geometry_group | 意味 |
|---|---|
| length_only | 長さだけ超過 |
| thickness_only | 厚みだけ超過 |
| both_exceeded | 両方超過 |
| within_limits | 両方とも範囲内。接触の参照群 |
| unknown_geometry | 必要値がNULL、または不正な負値 |

スイング抽選記録が1、または接触種別がSwungAndMiss/Solid/Weak/Marginalの行を対象にする。
見送り記録のゼロ埋めを接触とみなさない。診断列がない旧記録でもスイング種別があれば
全体分類に含め、カウント・コース・タイミングがない場合はunknownとして残す。

1. 記録の充足と整合性。現行の範囲でconsistent以外が出たら先に確認する。
2. 全スイングの分類構成と上流誤差平均。
3. 2ストライクかどうか × ゾーン内外 × 適応後のタイミング誤差絶対値帯 × 分類。
4. 空振りの1球単位一覧。必要ならWHERE条件を加えて絞り込む。

件数の割合の分母は空振りだけではなく全スイング（3本目は各層の全スイング）。
whiffs列も併記する。unknownは分母から勝手に除外しない。
タイミングは `adapted_timing_offset_sec` を使用する。HLA生成時のMarginalContact向けに
再抽選された値と混同しない。各平均はNULLを除くため、3本目はタイミング記録数も表示する。
位置はm、集計の表示だけcm、タイミングは秒からmsへ換算する。
ゾーン判定は実コースの正規化座標で、両座標の絶対値1以下がゾーン内。

本変更は診断の追加だけで、見送り・空振り・EV・HLA・VLAや乱数消費を変えない。
接触判定0.16mとEV減衰0.35mは現在の値を維持する。35cmへ広げた場合の接触可能性を
この集計だけで確定しない（厚み・姿勢・タイミングの制約が同時に残る）。
both_exceededが多ければ長さ限界だけを広げても当たらない。
length_onlyが多い場合は長さ方向のモデルと限界、thickness_onlyが多い場合は厚み方向を調べる。
タイミングと幾何誤差は関連するため、平均値だけからどちらか一つを原因と断定しない。

まず1〜3本目の結果を確認し、その後に接触限界・誤差変換・角度生成の修正範囲を決める。
