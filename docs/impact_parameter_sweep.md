# 局所打点b/Rを掃引する衝突診断

投球速度、バットの接触点速度、軸姿勢、軸方向打点を固定し、符号付き局所打点 `b/R` を等間隔に変える。弱いフェア方向打球が衝突式のどの条件で出るかを調べる診断。DB・入力CSV・試合・接触探索は不要。

```sh
python3 tools/diagnostics/impact_parameter_sweep.py \
  --output-dir ../saberbb_impact_sweep
```

既定値: 投球38m/s、バット接触点35m/s、速度角5度、軸傾き-45/-30/0/30/45度、軸方向打点-0.10/0/+0.10m、回転半径0.9m。b/Rは-0.999〜+0.999の2001点、間隔0.000999。15ケース×2001点×3モデル=90,045応答行。+軸方向はバットの先端側。軸傾きの負値は先端側が下向き、正値は上向き。左右の一方を標準座標として構成し、打者集団の標本とは扱わない。

速度条件を変える例:

```sh
python3 tools/diagnostics/impact_parameter_sweep.py \
  --output-dir ../saberbb_impact_sweep_30 \
  --bat-speed-ms 30
```

`--pitch-speed-ms`、`--bat-speed-ms`、`--attack-deg`、`--tilts-deg`、`--axials-m`、`--samples`、`--b-limit`、`--lever-m` で変更できる。samplesは3以上の奇数で、b=0を含む。b-limitは0より大きく1未満で、厳密な接線接触は含めない。軸方向打点は側面の範囲±0.16mまで。位置別反発曲線の範囲外は未評価として保存する。

投球は世界-Y、速度角はバット点速度のY/Zから構成する。投球回転の既定値は2200rpm・角度0度・効率0.9、gyroなし。これらは実験用の仮定で、実データから推定していない。`--spin-rpm`、`--spin-angle-deg`、`--spin-efficiency`、`--gyro-sign` で変更できる。従来のpitch_spin_sourceと同じ世界ベクトル再構成式を使う。

## 幾何とモデル

軸aと接触点の相対中心速度uから、軸に垂直な接近基底 `f=-normalize(u-a*(u·a))`、円周基底 `c=a×f` を作り、`n=sqrt(1-b*b)*f+b*c` を法線に使う。各グリッド点で法線の単位長・軸との直交・局所bの再構成を検査する。

接触点の世界速度は軸方向ケースごとに同じに固定する。角速度は `a×Vbat/lever`、軸方向並進を許す。有限半径ソルバーが接触点速度と重心からの腕から重心速度を導くため、軸方向ケースを跨ぐと重心速度も変わる。これは同じ一本のバットの全軌道を生成する実験ではなく、各局所衝突条件の感度実験。

モデルは既存と同じ `normal_profile`、`finite_mu0`、`finite_I0.00015_et0.4`。normal_profileは独立した法線反発ソルバーで計算し、finite_mu0との出射速度一致を確認する。質量・慣性・反発曲線・基準位置対応は既存bat_vibration_profileを使い、メタデータにも記録する。曲線の校正や係数変更はしない。

## 出力

| ファイル | 内容 |
| --- | --- |
| `impact_sweep_samples.csv` | 全グリッド点の法線・状態・方向・EV/HLA/VLA・出射速度・回転数 |
| `impact_sweep_summary.csv` | ケース/モデル別のグリッド点数、成功・フェア・EV<25m/sの点数、最小EVとそのb/R |
| `impact_sweep_minima.csv` | 全成功・フェア方向それぞれでEVが最小のグリッド点の詳細 |
| `impact_sweep_weak_fair_intervals.csv` | EV<25m/sかつフェア方向となる連続グリッド区間 |
| `impact_sweep_checks.csv` | 幾何・保存則・対照応答の最大誤差 |
| `impact_sweep_metadata.json` | 全入力条件、グリッド間隔、モデルの由来 |

区間の両端は弱いフェア方向打球に該当した最初と最後のグリッド点で、閾値の補間推定ではない。区間が存在しない場合はヘッダーのみ。最小EVは探索したグリッド上の最小値で、連続領域の厳密な大域最小値や未探索の条件まで保証しない。フェア方向は衝突直後の水平角判定。

グリッド点数の比率は実際の発生確率ではない。一様b/R分布や今回の入力条件が実際の打者に一致するとは仮定しない。実データの低EV不足を説明するには、条件別の実際の接触分布との照合が必要。

## 初回実行で確認した結果

既定条件の主モデルでは、15ケースの全グリッドでEV<25m/sの点は0。最も低いフェア方向EVは約25.900m/s（軸水平、先端側+0.10m）。軸方向打点0では、フェア方向の最小EVは軸水平で34.220m/s、+30度で37.464m/s、+45度で39.897m/sだった。

追加感度実験（軸水平、投球38m/s、速度角5度、1001点）では:

| バット点速度 | 軸方向打点0の最小フェアEV | 先端側+0.10mの最小フェアEV |
| --- | --- | --- |
| 30m/s | 32.266m/s | 23.240m/s |
| 20m/s | 27.529m/s | 16.726m/s |

弱いフェア打球を式が一切生成できないわけではない。一方、今回の速度と打点条件には、b/Rを変えても低EVに届かない領域がある。この結果は、実データの打点分布だけでなく、バット点速度・軸方向打点・応答モデルの組み合わせを調べる根拠になる。
