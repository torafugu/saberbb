# 根元寄りの打点：局所速度・剛体反動・振動を含む有効反発の分離

## 目的

バットの根元寄りで球のEVが変わる要因を、局所速度・剛体反動・打点依存の有効反発係数へ分けて調べる。
根元側の打点ほど、必ずすべての要因がEVを下げるとは仮定しない。
重心へ近づくことで剛体としての有効質量が大きくなり、反動の面で有利になる場合もある。
弱いゴロの目標率を設定したり、身体へ逃げる分として任意の損失を追加したりしない。

## 実行

以前の観測更新出力の3ファイルをそのまま使う。

- observation_update_contacts.csv
- observation_update_metadata.json
- observation_update_coverage.csv

```sh
python3 tools/diagnostics/axial_response_probe.py \
  --input-dir ../saberbb_observation_update \
  --output-dir ../saberbb_axial_response
```

試合・接触探索の再実行、DB移行は不要。入力の改変や既存出力への上書きを行わない。
入力異常で停止した場合、部分出力を結果に使わず、原因を確認して新しい出力先へ再実行する。
個別事例は先頭500接触を出力する。`--sample-limit 0` で省略できる。
先頭順なので、代表標本や打点別の均等抽出とは解釈しない。

## 共通入力と基準点

バット仕様と文献の有効反発曲線は前のNathanプリセットを継承する。
保存座標s=0をノブからz=0.71 m、重心をz=0.564 mへ対応させる仮定も維持する。
打点のマイナス側を「保存基準点に対して根元寄り」と呼ぶ。
**手元・グリップそのものへの衝突を再現しているわけではない。**
曲線の適用範囲はz=0.54〜0.84 mの側面だけ。端部・範囲外は未評価として残し、外挿しない。
今回の保存形状にはsの範囲制限もある。実際の打点の分布はcoverageとsummaryで確認する。
文献の高速度曲線はモデル計算の概読テンプレートであり、保存入力に対する実測校正値ではない。

各接触の法線n・軸a・投球速度・幾何打点は固定し、基準点での接触点速度を次で求める。

```text
v_reference = v_saved - omega × (a * s)
```

速度の絶対値に加え、法線方向速度と法線接近速度を記録する。
衝突に効くのは単なるバット速度の大きさだけではない。

## 3要因×全8通り

| 要因 | 基準 | 実際の保存打点 |
|---|---|---|
| local_velocity | 上式のv_reference | 保存された接触点速度 |
| rigid_recoil | 同じバットのs=0での逆有効質量 | 保存sでの逆有効質量 |
| positional_e | e=0.5 | Fig.12実線のe_eff(z) |

maskのbit 0/1/2がそれぞれの「実際側」を表す。mask=0が全要因基準、mask=7が全要因実際。
mask=7は前のnathan_fig12_full_speedと一致することをチェックする。
一定有効質量0.6 kgへの変更を混ぜず、3要因を同じNathanバット上で比較する。

これは各接触における**パラメータ正規化の比較**である。
法線や球の入力を固定しているので、異なる位置へ本当に当て直した8回のスイングではない。
特に速度と反動腕を別々に切り替える組み合わせは、同じ重心軌道を持つ1本のバットとして実現するとは限らない。
保存打点とEVの単純な相関より要因を分けて見られるが、独立した実験上の因果効果と断定しない。

## EVと球の並進エネルギーへの符号付き寄与

EVはベクトルの大きさで非線形なので、要因を変える順番によって差分が変わる。
全6順序の限界差分を平均するShapley分解を、EVと球の並進エネルギーに適用する。

```text
局所速度の寄与 + 剛体反動の寄与 + 有効eの寄与 = 実際値 - 基準値
```

寄与が負なら基準より低下、正なら上昇。百分率やそれぞれ独立の物理的散逸ではない。
平均寄与に加え、正/負の接触件数を出力する（絶対値1e-10以下はゼロ扱い）。
全8通りが接近衝突となる共通集合だけで分解する。
基準化で非接近となる接触はEV=0に置き換えず、`eligible:counterfactual_nonapproaching` として残す。
その接触でも実際のmask=7の応答とエネルギー収支はsummaryに記録する。
factorial各平均には各maskのimpulse_contacts、attributionにはcomplete_contactsの分母を使う。

## エネルギー収支と身体への伝達

mask=7について、球の並進エネルギー、バット重心の並進・横回転エネルギーをワールド座標で前後比較する。
バット重心速度は保存接触点速度からomega×打点腕を引いて求める。

```text
球の衝突前エネルギー + バットの衝突前エネルギー
 = 球の衝突後エネルギー + バットの衝突後エネルギー + 有効損失
```

`bat_energy_change_j` は符号付き。動いているバットは球へ仕事をするため、通常は負にもなり得る。
正の項をすべて「球から逃げたエネルギー」と呼ばない。

有効損失は球の変形・バット振動などをまとめたe_effの損失であり、
**計測されたバット振動エネルギーでも、手・腕・身体へ吸収された量でもない。**
文献曲線に含めた振動の影響へ、追加の「身体損失係数」を掛けない。
身体への伝達を定量化するには、将来、柔軟バットと手元の境界条件を時間発展させるモデルが必要。
その際は有効eにまとめた振動応答を明示的モデルへ置き換え、二重計上を避ける。

根拠は [Nathan (2000), Dynamics of the baseball–bat collision](https://baseball.physics.illinois.edu/AJP-Nov2000.pdf)。
エネルギー分配はSec.II D/E、グリップへの伝播と時間遅れはFig.13〜15付近を参照。
[著者によるグリップの解説](https://baseball.physics.illinois.edu/grip.html)も参照できる。
通常のバレル衝突についてのグリップの影響の小ささを、手元近傍へ一般化しない。
今回の計算は柔軟バットの振動モードや手・腕を直接積分しない。

## 出力と確認順

| ファイル | 内容 |
|---|---|
| axial_response_coverage.csv | 元試行数、適用可能・未評価・基準化で非接近となる件数 |
| axial_response_checks.csv | 元接触再現、全8通りの反発則・力積・エネルギー、寄与分解の閉合 |
| axial_response_status.csv | variant別の評価状態 |
| axial_response_summary.csv | 打点、局所速度・有効質量・有効e・実際と基準のEV、エネルギー収支 |
| axial_response_attribution.csv | 打点別の3要因の符号付き寄与（EVはm/s、ball_energyはJ） |
| axial_response_factorial.csv | 全8通りの平均EV・球の並進エネルギー、各分母とフェア方向件数 |
| axial_response_examples.csv | 先頭事例の打点・エネルギー・個別寄与 |
| axial_response_metadata.json | 入力ハッシュ、バット仕様、基準化と適用範囲など全仮定 |

最初は **coverage・checks・status・summary・attributionの5 CSV** を添付する。
factorialとmetadataも保持し、寄与の順序依存や条件を追跡できるようにする。

1. coverageとchecksを確認する。元728,430試行・514,997接触の同じ入力なら再現すること。
2. `all_swings / observed_sigma_0.005_r0.9` を基準条件とする。
3. `stage=source_z` のband_1で、根元寄り→基準点→先端寄りの速度・有効質量・eを比較する。
4. 同じ区分のattributionで、局所速度やeの負寄与を、反動の正寄与が相殺しているか確認する。
5. フェア方向に限定するなら `stage=source_z_direction / band_2=fair_direction` を使う。
   mask=7の方向で集合を固定するので、全maskで同じ接触集合を比較できる。
6. overall/source_zの平均はファウルも含む。fair_contactsの列だけでは平均をフェアに限定しない。
7. summaryのn_列とattributionのcomplete_contactsが異なる場合、非接近の基準化がある。
   分母の違う平均を差し引かず、分解の閉合はattribution内で確認する。

scope・variant・stage・maskは同じ接触の別の見方であり、合算しない。
打点分布と実際の野球の比較をせずに、弱打の不足・過剰を結論しない。
