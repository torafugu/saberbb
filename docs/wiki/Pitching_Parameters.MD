# Pitching Parameters

Pitching-related parameters are defined in `src/domain/shared/player.rs`, generated by `src/domain/player_factory.rs`, loaded through `src/domain/player_service.rs`, persisted by `src/repositories/player_repository.rs`, and consumed by `src/domain/resolver/pitching_resolver.rs`.

Pitching is now generated and persisted for players with `FielderType::Pitcher`.

## PitcherInfo

`PitcherInfo` stores pitcher-level attributes, pitch inventory, and pitcher fielding info.

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `height` | `f64` | `pitcher_info.height` | Pitcher height. Used to derive release height. |
| `extension` | `f64` | `pitcher_info.extension` | Pitch extension. Release-point calculation clamps it between `PITCH_EXTENSION_MIN = 1.2` and `PITCH_EXTENSION_MAX = 2.3`. |
| `throw_side` | `RL` | `pitcher_info.throw_side` | Throwing side. Values: `Right`, `Left`. |
| `arm_slot` | `ArmSlot` | `pitcher_info.arm_slot` | Delivery arm slot. Used for release point and base spin angle. |
| `pitcher_style` | `PitcherStyle` | `pitcher_info.pitcher_style` | Pitcher archetype used to choose pitch types. |
| `velocity` | `f64` | `pitcher_info.velocity` | Pitcher-level velocity multiplier/base value. |
| `control` | `f64` | `pitcher_info.control` | Pitcher-level control value. |
| `stamina` | `f64` | `pitcher_info.stamina` | Pitcher-level stamina value. |
| `injury_proneness` | `f64` | `pitcher_info.injury_proneness` | Pitcher-level injury-proneness value. |
| `clutch` | `f64` | `pitcher_info.clutch` | Pitcher-level clutch value. Current factory code generates this from `pitcher_info_probs.injury_proneness`. |
| `hpp` | `f64` | `pitcher_info.hpp` | Home-away splitting value. |
| `platoon_splitting` | `f64` | `pitcher_info.platoon_splitting` | Platoon-splitting value. |
| `delivery_motion_time` | `f64` | `pitcher_info.delivery_motion_time` | Delivery motion time, also used by fielding/running resolution. |
| `pitch_skills` | `Vec<PitchSkill>` | `pitch_skill` | Pitch-specific values and usage scores. |
| `fielder_info` | `FielderInfo` | `fielder_info` | Pitcher fielding info stored with `FielderType::Pitcher`. |

## PitchSkill

`PitchSkill` stores pitch-specific values for each pitch type in a pitcher's inventory.

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `pitch_type` | `PitchType` | `pitch_skill.pitch_type` | Pitch type. Together with `player_id`, this is the primary key. |
| `velocity` | `f64` | `pitch_skill.velocity` | Pitch-specific velocity factor. `create_pitch()` multiplies `pitcher.velocity * pitch_skill.velocity`. |
| `control` | `f64` | `pitch_skill.control` | Pitch-specific control value. |
| `stamina` | `f64` | `pitch_skill.stamina` | Pitch-specific stamina value. |
| `injury_proneness` | `f64` | `pitch_skill.injury_proneness` | Pitch-specific injury-proneness value. |
| `spin_rate` | `f64` | `pitch_skill.spin_rate` | Pitch spin rate before random and speed adjustments. |
| `spin_angle` | `f64` | `pitch_skill.spin_angle` | Pitch-specific spin-angle offset from the pitcher's base spin angle. |
| `spin_efficiency` | `f64` | `pitch_skill.spin_efficiency` | Fraction of spin that contributes to Magnus movement. |
| `usage` | `f64` | `pitch_skill.usage` | Usage score. Pitch selection applies `softmax` to all usage values. |

## Arm Slots

`ArmSlot` controls the pitcher's base spin angle and release point.

| Value | Base spin angle for right-handed pitchers | Release height factor | Release side distance |
| --- | --- | --- | --- |
| `Overhand` | `25.0` degrees | `1.05 * height` | `0.35` |
| `ThreeQuarter` | `55.0` degrees | `0.95 * height` | `0.55` |
| `Sidearm` | `85.0` degrees | `0.70 * height` | `0.85` |
| `Submarine` | `115.0` degrees | `0.40 * height` | `0.60` |

Left-handed pitchers mirror the base spin angle with `(360.0 - base_deg) % 360.0` and negate release `x`.

## Pitcher Styles

`PitcherStyle` is used to choose the pitch types a pitcher can throw.

| Value | Meaning |
| --- | --- |
| `PowerPitcher` | Power pitcher. |
| `FinessePitcher` | Finesse pitcher. |
| `BalancedPitcher` | Balanced pitcher. |

Pitch-type weights are loaded from `item_weighted` for each style by `PlayerService::load_pitch_type_prob()`.

## Generation Sources

`PlayerFactory::load_player_probs()` loads pitching probabilities before generating players.

| Generated field | Source |
| --- | --- |
| `throw_side` | `item_weighted`: `pitcher_info/throw_side` |
| `arm_slot` | `item_weighted`: `pitcher_info/arm_slot` |
| `pitcher_style` | `item_weighted`: `pitcher_info/pitcher_style` |
| `height` | `normal_param`: `player/pitcher_info/height` |
| `extension` | `normal_param`: `player/pitcher_info/extension` |
| `velocity` | `normal_param`: `player/pitcher_info/velocity` |
| `control` | `normal_param`: `player/pitcher_info/control` |
| `stamina` | `normal_param`: `player/pitcher_info/stamina` |
| `injury_proneness` | `normal_param`: `player/pitcher_info/injury_proneness` |
| `clutch` | Loaded from `normal_param`: `player/pitcher_info/clutch`; current factory assignment uses `injury_proneness` instead. |
| `hpp` | `normal_param`: `player/pitcher_info/hpp` |
| `platoon_splitting` | `normal_param`: `player/pitcher_info/platoon_splitting` |
| `delivery_motion_time` | `normal_param`: `player/pitcher_info/delivery_motion_time` |
| pitch inventory | `item_weighted`: `pitcher_style/<PitcherStyle>` |
| pitch-skill fields | `normal_param`: `pitch_type/<PitchType>/{velocity,control,stamina,injury_proneness,spin_rate,spin_angle,spin_efficiency,usage}` |

Generation happens only when a generated player includes `FielderType::Pitcher`. Primary pitchers have `offense_skills.batter = None`.

## Persistence

Pitching data is saved as part of `SqlPlayerRepository::insert_player()`.

| Table | Purpose |
| --- | --- |
| `pitcher_info` | One pitcher-level row per pitcher player. Primary key: `player_id`. |
| `pitch_skill` | One row per pitch type for the player. Primary key: `(player_id, pitch_type)`. |
| `fielder_info` | Pitcher fielding row with `fielder_type = Pitcher`. |

`GameRepository::load_pitcher_info()` loads the pitcher row, then attaches `pitch_skills` from `pitch_skill` and pitcher `fielder_info` from `fielder_info`.

## Release Point

`PitcherInfo::calculate_release_point()` derives release coordinates:

| Coordinate | Formula |
| --- | --- |
| `x` | Arm-slot side distance; negated for left-handed pitchers. |
| `y` | `18.44 - extension.clamp(1.2, 2.3)` |
| `z` | `height * arm_slot_height_factor` |

## Pitch Creation

`create_pitch(rng, pitcher)` converts pitcher parameters into a `PitchedBall`.

| Output | Formula or source |
| --- | --- |
| `pitch_type` | Sampled from `pitcher.pitch_skills` by softmax of `usage`. |
| `speed_kmh` | `pitcher.velocity * pitch_skill.velocity * rng.normal_factor_std_1percent()` |
| `spin_rate` | `pitch_skill.spin_rate * rng.normal_factor_std_1percent() * (speed_kmh / 150.0)` |
| `spin_angle` | Right-handed: `base_spin_angle + pitch_skill.spin_angle`; left-handed: `base_spin_angle - pitch_skill.spin_angle`; normalized to `0..360`. |
| `spin_efficiency` | `pitch_skill.spin_efficiency` |
| `release_point` | `pitcher.calculate_release_point()` |
| `flight_time` | `release_point.y / ((speed_kmh / 3.6) * 0.95)` |
| `norm_x`, `norm_y` | Currently initialized to `0.0`. |

Constants used by pitching resolution:

| Constant | Value | Meaning |
| --- | --- | --- |
| `BASE_FOUR_SEAM_SPEED` | `150.0` | Reference speed for spin-rate speed adjustment. |
| `AIR_DRAG_FACTOR` | `0.95` | Average-speed factor used for flight-time calculation. |
| `MAGNUS_FORCE_BASE_SPIN_RATE` | `2300.0` | Spin-rate baseline for movement displacement. |

## Pitch Movement

`calculate_pitch_displacement(ball)` estimates movement from spin:

| Component | Behavior |
| --- | --- |
| horizontal | `sin(spin_angle)` times spin strength, scaled and clamped to `-1.0..1.0`. |
| vertical | Difference from a standard fastball backspin reference, scaled and clamped to `-1.0..1.0`. |

`calculate_late_break_displacement(ball, expected_ball)` compares actual and expected Magnus acceleration during the final 40% of flight time. `calculate_total_pitch_offset(ball, matchup, expected_ball)` combines base movement, late break, and handedness-based crossfire perception.

| Matchup | Crossfire multiplier |
| --- | --- |
| Left-handed pitcher vs right-handed batter | `1.30` |
| Right-handed pitcher vs left-handed batter | `1.05` |
| Same-side or other matchup | `1.00` |

`calculate_timing_offset(ball, expected_ball)` compares actual flight time to expected flight time using the midpoint standard extension `(1.2 + 2.3) / 2.0`.

| Distribution | Source |
| --- | --- |
