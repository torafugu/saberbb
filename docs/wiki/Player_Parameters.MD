# Player Parameters

Player parameters are defined mainly in `src/domain/shared/player.rs` and persisted by `src/repositories/player_repository.rs`.

## Player

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `id` | `u32` | `player.id` | Player identifier. The database uses an autoincrement id when saving new players. |
| `first_name` | `Arc<str>` | `player.first_name` | Player first name. Generated from the first name table for the current language. |
| `last_name` | `Arc<str>` | `player.last_name` | Player last name. Generated from the last name table for the current language. |
| `age` | `u8` | `player.age` | Player age. Generated from a gamma distribution. |
| `throw` | `RL` | `player.throw` | Throwing hand. Values: `Right`, `Left`. |
| `mod_speed` | `f64` | `player.mod_speed` | Speed modifier. Generated by a skewed normal random value. |
| `mod_control` | `f64` | `player.mod_control` | General control modifier. Generated by a skewed normal random value. |
| `defensive_skills` | `Vec<DefensiveSkill>` | `defensive_skill` | Defensive positions and defensive modifiers. Currently generation assigns one defensive skill. |
| `bat` | `RL` | `player.bat` | Batting side. Values: `Right`, `Left`. |
| `mod_ba` | `f64` | `player.mod_ba` | Batting average modifier. Used to derive hit average. |
| `mod_slg` | `f64` | `player.mod_slg` | Slugging modifier. Used to derive slugging percentage. |

## Handedness

`RL` represents right or left handedness.

| Value | Meaning |
| --- | --- |
| `Right` | Right-handed thrower or batter. |
| `Left` | Left-handed thrower or batter. |

## Defensive Skill

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `position` | `Position` | `defensive_skill.position` | Defensive position for the skill. |
| `mod_uzr` | `f64` | `defensive_skill.mod_uzr` | Defensive range/value modifier. Generated by a skewed normal random value. |

Available positions are defined in `src/domain/shared/types.rs`.

| Value | Meaning |
| --- | --- |
| `P` | Pitcher |
| `C` | Catcher |
| `FB` | First base |
| `SB` | Second base |
| `TB` | Third base |
| `SS` | Shortstop |
| `LF` | Left field |
| `CF` | Center field |
| `RF` | Right field |
| `DH` | Designated hitter |

`Position::ALL_NO_DH` contains every position except `DH`. The current sample position probabilities do not include `DH`.

## Derived Batting Values

The raw batting modifiers are converted to baseball-facing values with a sigmoid curve.

| Derived value | Formula | Range |
| --- | --- | --- |
| `hit_average()` | `0.26 + 0.12 * (sigmoid(mod_ba) - 0.5)` | Approaches `0.200` to `0.320` |
| `slg()` | `0.425 + 0.25 * (sigmoid(mod_slg) - 0.5)` | Approaches `0.300` to `0.550` |

At `mod_ba = 0`, `hit_average()` returns `0.260`.

At `mod_slg = 0`, `slg()` returns `0.425`.

## Default Constructors

| Constructor | Behavior |
| --- | --- |
| `Player::default()` | Creates player id `1`, default name `DEAFULT`, age `25`, right throw, right bat, and zero modifiers. |
| `Player::min(id, first_name, last_name)` | Creates a minimal right-handed player with age `25` and zero modifiers. |
| `Player::batter(id, first_name, last_name, mod_ba, mod_slg)` | Creates a minimal batter with the supplied batting modifiers. |
