# Player Parameters

Player parameters are defined mainly in `src/domain/shared/player.rs`, generated by `src/domain/player_factory.rs`, loaded through `src/domain/player_service.rs`, and persisted by `src/repositories/player_repository.rs`.

The current `Player` model is nested:

| Field | Type | Description |
| --- | --- | --- |
| `info` | `PlayerInfo` | Identity and display information. |
| `offense_skills` | `OffenseSkills` | Batting and running skills. |
| `defense_skills` | `DefenseSkills` | Primary position and defensive or pitching skills. |

## PlayerInfo

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `id` | `i64` | `player_info.id` | Player identifier. New generated players are created with `id = 0`; SQLite assigns the saved id with `AUTOINCREMENT`. |
| `first_name` | `String` | `player_info.first_name` | Player first name. Generated from the first-name table for the current language. |
| `last_name` | `String` | `player_info.last_name` | Player last name. Generated from the last-name table for the current language. |
| `age` | `u8` | `player_info.age` | Player age. Generated from `gamma_param` where category is `player/player_info` and name is `age`. |
| `uniform_number` | `u8` | `player_info.uniform_number` | Uniform number. Generated from `0..100`; uniqueness is not currently enforced. |

`PlayerInfo::full_name()` formats names through the global `I18nManager`.

## OffenseSkills

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `batter` | `Option<BatterInfo>` | `batter_info` | Batting parameters. The factory currently assigns this for non-pitchers and leaves it `None` for primary pitchers. |
| `running` | `RunningSkills` | `running_skills` | Running parameters. Generated and saved for every player. |

## BatterInfo

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `batting_side` | `RL` | `batter_info.batting_side` | Batting side. Values: `Right`, `Left`. |
| `swing_speed` | `f64` | `batter_info.swing_speed` | Swing speed. Generated from `normal_param` under `player/batter_info/swing_speed`. |
| `base_launch_angle` | `f64` | `batter_info.base_launch_angle` | Base launch angle in degrees. Generated from `normal_param` under `player/batter_info/base_launch_angle`. |
| `consistency_sigma` | `f64` | `batter_info.consistency_sigma` | Contact consistency spread. Generated from `normal_param` under `player/batter_info/consistency_sigma`. |
| `weight_foul_pull` | `f64` | `batter_info.weight_foul_pull` | Field-sector weight for foul pull-side contact. |
| `weight_pull` | `f64` | `batter_info.weight_pull` | Field-sector weight for pull-side contact. |
| `weight_center` | `f64` | `batter_info.weight_center` | Field-sector weight for center contact. |
| `weight_opposite` | `f64` | `batter_info.weight_opposite` | Field-sector weight for opposite-field contact. |
| `weight_foul_opposite` | `f64` | `batter_info.weight_foul_opposite` | Field-sector weight for foul opposite-side contact. |

The field-sector weights are selected by first choosing a `HitterTendency` (`Normal`, `Pull`, or `Spray`), then loading sector weights from the `hitter_tendency/<tendency>` item weights.

## RunningSkills

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `speed` | `f64` | `running_skills.speed` | Base running speed in meters per second. Generated from `normal_param` under `player/running_skills/running_speed`. |
| `lead_distance` | `f64` | `running_skills.lead_distance` | Runner lead distance in meters. Generated from `normal_param` under `player/running_skills/lead_distance`. |
| `start_reaction` | `f64` | `running_skills.start_reaction` | Runner start reaction. Generated from `normal_param` under `player/running_skills/start_reaction`. |

## DefenseSkills

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `position` | `Position` | `defense_skills.position` | Primary defensive position. |
| `pitcher` | `Option<PitcherInfo>` | `pitcher_info`, `pitch_skill`, `fielder_info` | Pitcher parameters and pitcher fielding info. Set when the player has `FielderType::Pitcher`. |
| `catcher` | `Option<CatcherInfo>` | `fielder_info` | Catcher fielding info. Set when the player has `FielderType::Catcher`. |
| `middle_infielder` | `Option<FielderInfo>` | `fielder_info` | Middle-infielder fielding info. Set for `SB` and `SS` type skills. |
| `corner_infielder` | `Option<FielderInfo>` | `fielder_info` | Corner-infielder fielding info. Set for `FB` and `TB` type skills. |
| `outfielder` | `Option<FielderInfo>` | `fielder_info` | Outfielder fielding info. Set for `LF`, `CF`, and `RF` type skills. |

`DefenseSkills::new(position)` sets the primary position and initializes all optional skill groups to `None`.

## FielderInfo

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `fielder_type` | `FielderType` | `fielder_info.fielder_type` | Defensive skill group. `DH` is a position, not a `FielderType`. |
| `throw_speed` | `f64` | `fielder_info.throw_speed` | Throw speed in meters per second. |
| `running_speed` | `f64` | `fielder_info.running_speed` | Fielding running speed in meters per second. |
| `reaction` | `f64` | `fielder_info.reaction` | Fielding reaction time in seconds; lower is better. |
| `prep_time` | `f64` | `fielder_info.prep_time` | Throw preparation or transfer time in seconds; lower is better. |

All `FielderInfo` numeric values are generated from `normal_param` under `player/fielder_info`.

## PitcherInfo

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `height` | `f64` | `pitcher_info.height` | Pitcher height. |
| `extension` | `f64` | `pitcher_info.extension` | Pitch extension. Release-point calculation clamps it between `1.2` and `2.3`. |
| `throw_side` | `RL` | `pitcher_info.throw_side` | Pitcher throwing side. Values: `Right`, `Left`. |
| `arm_slot` | `ArmSlot` | `pitcher_info.arm_slot` | Delivery arm slot. |
| `pitcher_style` | `PitcherStyle` | `pitcher_info.pitcher_style` | Pitcher archetype used to choose pitch types. |
| `velocity` | `f64` | `pitcher_info.velocity` | Pitcher-level velocity value. |
| `control` | `f64` | `pitcher_info.control` | Pitcher-level control value. |
| `stamina` | `f64` | `pitcher_info.stamina` | Pitcher-level stamina value. |
| `injury_proneness` | `f64` | `pitcher_info.injury_proneness` | Pitcher-level injury-proneness value. |
| `clutch` | `f64` | `pitcher_info.clutch` | Pitcher-level clutch value. |
| `hpp` | `f64` | `pitcher_info.hpp` | Home-away splitting value. |
| `platoon_splitting` | `f64` | `pitcher_info.platoon_splitting` | Platoon-splitting value. |
| `delivery_motion_time` | `f64` | `pitcher_info.delivery_motion_time` | Delivery motion time. |
| `pitch_skills` | `Vec<PitchSkill>` | `pitch_skill` | Pitch-specific skill values and usage. |
| `fielder_info` | `FielderInfo` | `fielder_info` | Pitcher fielding info, stored as `FielderType::Pitcher`. |

PitcherInfo also derives:

| Method | Behavior |
| --- | --- |
| `calculate_release_point()` | Calculates release `(x, y, z)` from height, extension, arm slot, and throw side. |
| `base_spin_angle()` | Returns the fastball base spin angle for the arm slot, mirrored for left-handed pitchers. |
| `pitch_type_distribution()` | Applies `softmax` to pitch-skill `usage` values. |
| `pitch_calling_distribution()` | Combines pitch-type distribution with the default location distribution. |
| `sample_pitch_type(rng)` | Samples a `PitchSkill` by pitch-type distribution. |

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `pitch_type` | `PitchType` | `pitch_skill.pitch_type` | Pitch type. |
| `velocity` | `f64` | `pitch_skill.velocity` | Pitch-specific velocity value. |
| `control` | `f64` | `pitch_skill.control` | Pitch-specific control value. |
| `stamina` | `f64` | `pitch_skill.stamina` | Pitch-specific stamina value. |
| `injury_proneness` | `f64` | `pitch_skill.injury_proneness` | Pitch-specific injury-proneness value. |
| `spin_rate` | `f64` | `pitch_skill.spin_rate` | Pitch spin rate. |
| `spin_angle` | `f64` | `pitch_skill.spin_angle` | Pitch spin angle. |

Pitch skills are generated from `normal_param` rows under `pitch_type/<PitchType>`. The available pitch types are selected from `item_weighted` rows under `pitcher_style/<PitcherStyle>`.

## Generation Notes

`PlayerFactory::load_player_probs()` loads all probability inputs before generation:

| Loader | Source |
| --- | --- |
| `load_player_info_probs()` | `gamma_param`: `player/player_info/age` |
| `load_running_skill_probs()` | `normal_param`: `player/running_skills/*` |
| `load_batter_info_probs()` | `item_weighted`: `player/batting_side`, `player/hitter_tendency`; `normal_param`: `player/batter_info/*` |
| `load_field_sector_weights_prob()` | `item_weighted`: `hitter_tendency/<HitterTendency>` |
| `load_fielder_info_probs()` | `item_weighted`: `player/fielder_type`; `normal_param`: `player/fielder_info/*` |
| `load_pitcher_info_prob()` | `item_weighted`: `pitcher_info/throw_side`, `pitcher_info/arm_slot`, `pitcher_info/pitcher_style`; `normal_param`: `player/pitcher_info/*` |
| `load_pitch_type_prob()` | `item_weighted`: `pitcher_style/<PitcherStyle>` |
| `load_pitch_skill_probs()` | `normal_param`: `pitch_type/<PitchType>/*` |

Primary position is assigned from the first chosen `FielderType`:

| FielderType | Primary position weights |
| --- | --- |
| `Outfielder` | `RF` 0.32, `CF` 0.32, `LF` 0.32, `DH` 0.04 |
| `MiddleInfielder` | `SS` 0.48, `SB` 0.52 |
| `CornerInfielder` | `FB` 0.5, `TB` 0.4, `DH` 0.1 |
| `Pitcher` | Always `P` |
| `Catcher` | Always `C` |

The factory may add extra defensive skill groups from `multiple_fielder_type/<FielderType>`. Each generated player is assigned to the team with the fewest players at the player's primary position; if that lookup fails with `NotFound`, a random team is selected.

## Constructors And Helpers

| Constructor or helper | Behavior |
| --- | --- |
| `PlayerInfo::new_unsaved(first_name, last_name, age, uniform_number)` | Creates unsaved info with `id = 0`. |
| `PlayerInfo::new(id, first_name, last_name, age, uniform_number)` | Creates fully populated player info. |
| `PlayerInfo::new_min(id, first_name, last_name)` | Creates minimal player info with `age = 0` and `uniform_number = 0`. |
| `Player::from_player_info(info)` | Creates a `Player` with the supplied info, no batter or pitcher info, zeroed running skills, and `DefenseSkills::new(Position::DH)`. |
| `DefenseSkills::new(position)` | Creates defense skills for a primary position with all optional skill groups set to `None`. |
| `FielderInfo::new_pitcher()` | Creates zeroed pitcher fielding info. |
| `CatcherInfo::from_fielder_info(fielder_info)` | Wraps fielder info as catcher info. |
