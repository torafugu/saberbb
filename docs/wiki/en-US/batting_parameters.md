# Batting Parameters

Batting-related parameters are defined in `src/domain/shared/player.rs`, generated by `src/domain/player_factory.rs`, loaded through `src/domain/player_service.rs`, persisted by `src/repositories/player_repository.rs`, and consumed by `src/domain/resolver/batting_resolver.rs`.

Batting is generated and persisted for non-primary-pitcher players. Primary pitchers currently have `offense_skills.batter = None`.

## BatterInfo

`BatterInfo` stores batting-side, approach, zone profile, swing, contact, and consistency attributes.

| Parameter | Type | Stored in DB | Description |
| --- | --- | --- | --- |
| `batting_side` | `RL` | `batter_info.batting_side` | Batting side. Values: `Right`, `Left`. |
| `batter_type` | `BatterType` | `batter_info.batter_type` | Plate-approach archetype used by `sample_plate_approach()`. |
| `zone_aptitude` | `ZoneAptitude` | `batter_info.zone_aptitude` | Hot/cold-zone profile used by `zone_modifier()`. |
| `hot_zone_scale` | `f64` | `batter_info.hot_zone_scale` | Strength multiplier for the zone-aptitude modifier. |
| `batting_eye` | `f64` | `batter_info.batting_eye` | Pitch-recognition skill used by pitch timing perception. |
| `swing_speed` | `f64` | `batter_info.swing_speed` | Bat speed used for timing impact, exit velocity, and collision spin. |
| `swing_power` | `f64` | `batter_info.swing_power` | Power value used to scale swing contribution to exit velocity. |
| `attack_angle` | `f64` | `batter_info.attack_angle` | Baseline attack angle in degrees. |
| `bat_control` | `f64` | `batter_info.bat_control` | Contact-control skill used to adapt to pitch offset and reduce swing-angle error. |
| `consistency` | `f64` | `batter_info.consistency` | Batter-level consistency value. It is generated and persisted but is not currently used by batting resolution. |

## Batter Types

`BatterType` controls plate approach and attack-angle adjustment.

| Value | Meaning | Attack-angle modifier |
| --- | --- | --- |
| `AggressiveFreeSwinger` | Aggressive, feel-driven hitter. | `10.0` |
| `ClassicAnalyst` | Cautious, analytical hitter. | `2.0` |
| `GameManager` | Hitter that adapts to the game situation. | `3.0` |
| `ClutchHunter` | High-risk, power-oriented hitter. | `0.0` |

`default_plate_approach(batter_type)` currently returns only `PlateApproach::Aggressive` entries for every batter type, with different weights.

## Zone Aptitude

`ZoneAptitude` controls the Gaussian peaks used by `BatterInfo::zone_modifier(location)`.

| Value | Behavior |
| --- | --- |
| `Balanced` | One positive peak at zone center. |
| `InsideDominant` | Positive center peak plus an inside-zone peak. |
| `OutsideDominant` | Positive center peak plus an outside-zone peak. |
| `LowBaller` | Positive low-zone peak and negative high-zone penalty. |
| `HighBaller` | Positive high-zone peak and negative low-zone penalty. |
| `DiagonalCross` | Positive diagonal peaks with opposite diagonal penalties. |

`zone_modifier(location)` sums all matching Gaussian peaks and multiplies the result by `1.0 + hot_zone_scale`.

| Generated field | Source |
| --- | --- |
| `batting_side` | `item_weighted`: `player/batting_side` |
| `batter_type` | `item_weighted`: `player/batter_type` |
| `zone_aptitude` | `item_weighted`: `player/zone_aptitude` |

| `batting_eye` | `normal_param`: `player/batter_info/batting_eye` |
| `swing_speed` | `normal_param`: `player/batter_info/swing_speed` |
| `swing_power` | `normal_param`: `player/batter_info/swing_power` |

| `bat_control` | `normal_param`: `player/batter_info/bat_control` |

Generation happens only when the generated player's primary position is not `P`.

## Persistence

Batting data is saved as part of `SqlPlayerRepository::insert_player()`.

| Table | Purpose |
| --- | --- |
| `batter_info` | One batting row per non-primary-pitcher player. Primary key: `player_id`. |

`GameRepository::load_batter()` loads batter rows with batting side, batter type, zone aptitude, hot-zone scale, batting eye, swing speed, swing power, attack angle, bat control, and consistency.

## Batting Factor

`calculate_batting_factor(pitcher, batter, actual_pitch_type, expected_pitch_type, actual_location, expected_location)` compares the real pitch to the batter's expectation.

| Component | Source |
| --- | --- |
| `distance_from_zone_edge` | `actual_location.distance_from_zone_edge()`. |
| `zone_similarity` | Similarity between `actual_location.target_zone()` and `expected_location.target_zone()`. |
| `pitch_similarity` | Difference between actual and expected pitch-skill spin rate and spin angle. |
| `zone_aptitude` | `batter.zone_modifier(actual_location)`. |
| `total_modifier` | Average of `1.0 - zone_aptitude`, `1.0 - zone_similarity`, and `1.0 - pitch_similarity`. |

Zone similarity values:

| Case | Value |
| --- | --- |
| Actual and expected are both `Center` | `0.3` |
| Actual is `Center`, expected is not `Center` | `0.1` |
| Same target-zone bucket | `0.2` |
| Opposite target-zone bucket | `-0.2` |
| Same height or same course | `0.05` |

Pitch similarity is clamped to `-0.2..0.2`.

## Current execution and intent model

See [batting logic](batting_logic.md) for swing probability, two-strike protection, skill adaptation, zero additional spatial error and 0.75 timing displacement. See [batting physics](batting_physics.md) for current EV, signed-normal HLA v2, VLA and spin formulas.

`Player.batting_character` is a persistent `BatterCharacter` stored in `player_batting_character`, separately from BatterInfo and BatterType. Its situational preferences and the independent Manager produce diagnostic Intent; they do not yet replace live batting outcomes. See [batting strategy and managers](batting_strategy.md).
