# 意図別の差をゲーム単位の対応付きbootstrapで確認する

前回の[衝突応答診断](rust_intent_collision.md)の投球別結果を再利用し、
ContactFirstからLineDriveへ変えたときの接触率・フェア方向・角度帯・EV/VLAの差について区間を計算する。
狙い、監督／打者の判断規則、予測器、スイング、物理係数は変更しない。

## 入力

`rust_intent_collision_probe.py`が生成したフォルダをそのまま指定する。
共有用の6ファイルに加え、同じ実行で生成済みの`rust_intent_collision_details.csv`が必要。
summaryだけではゲーム内の依存や同一投球の対応を復元できないため、そこから擬似的な投球を生成しない。

読込時に次を確認する。

- 固定モデル・物理係数と、凍結済み狙い規則・応答モデルなどのコードハッシュ。
- 元の物理・照合checksが有限、非負、1e-7以内であること。
- game_id/count_seq順の各投球に、両意図が重複なく揃っていること。
- 監督指示／打者選好に対するselected・理由、予測高さ帯、固定狙い、状態とEV/VLAなどの整合性。
- 予測高さ0.6 m未満では両意図が同じ中心狙いとなり、結果も一致すること。
- detailsから再集計したsummary・pairs・statusと、coverage／metadataの件数が一致すること。
- ゲーム別集計を合計した点推定が、元の意図別／同一投球ペア集計の点推定と一致すること。

これは保存結果の整合性検査であり、接触探索や衝突応答の独立した再検証ではない。
入力ファイルをハッシュで記録する。元の記録は読み取りのみで変更しない。

## 再抽出の単位

比較可能な投球があるゲームIDをN個の観測クラスターとする。
各反復でNゲームを復元抽出し、ゲーム内の全比較投球を同じ回数だけ使用する。
両意図・すべての予測高さ帯・監督／打者設定のグループに同じゲーム抽出回数を使う。
片方の意図だけや各高さ帯だけを独立に再抽出しない。

各反復では抽出ゲームの件数・値の合計から率と平均を計算する。
ゲームごとの率を等重みで平均する方式ではなく、元の「対象投球全体の率・平均」と同じ推定対象を保つ。
selected_plansは入力検査で確認するが、bootstrapの比較は両意図の診断候補であるall_plansに限定する。

ゲームIDの数値範囲を連番の全ゲーム数とはみなさない。比較投球がないゲームを捏造しない。
観測ゲームが2未満なら停止する。coverageと各行にゲーム数を残す。

## 実行

```sh
python3 tools/diagnostics/rust_intent_game_bootstrap.py --input-dir ../saberbb_rust_intent_collision --output-dir ../saberbb_rust_intent_game_bootstrap --replicates 2000 --bootstrap-seed 0
```

既存の診断出力を使うため、DB参照・新しい試合の生成・接触探索・衝突再計算は不要。
このスクリプトはDBパスを受け取らず、`SABERBB_DB`も不要。
別のDB診断を実行するときのDBパス取得は引き続き`SABERBB_DB`を使う。
出力先は新しいフォルダを指定する。

既定は2000反復・seed文字列`0`・95%の両側percentile区間。
seedは独立した`random.Random`へ渡し、試合・グローバル乱数を使わない。
`--confidence`で信頼水準を指定できる。分位点は隣接順序統計量の線形補間。
反復数・seed・水準・入力ハッシュはmetadataに保存する。

## 指標と分母

推定値と区間はすべて **LineDrive − ContactFirst**。
符号が正だから戦略として良いとは限らない。高角度率の増加やフェア率の低下も併せて読む。

| 指標の末尾・種類 | 意味 |
| --- | --- |
| *_pct_per_searched_delta_pp | 各意図の探索計画を分母にした率の差。接触・応答成功・フェア方向・各角度帯 |
| *_pct_among_fair_delta_pp | 各意図の成功したフェア方向の応答を分母にした角度帯の率の差 |
| common_fair_*_delta_pp | 両意図ともフェア方向だった同一投球だけの角度帯の差 |
| mean_fair_*_delta | 各意図の成功フェア応答の平均EV・VLA・回転数の差 |
| common_fair_mean_delta_* | 両意図ともフェア方向だった同一投球だけのEV・VLA・回転数の平均差 |

率の単位はポイント、EVはm/s、VLAは度、回転数はrpm。
フェア方向・下向き・高角度・ライナー角度帯の定義は元の診断と同じ。
overallと予測高さ別の行は重複する。角度帯の平均改善と、対象集団の入れ替わりを区別するため、common_fairも併記する。

## 出力

先頭が`rust_intent_game_bootstrap_`の4ファイルを共有する。

- `summary.csv`：グループ・指標別の点推定、区間下限／上限、定義できた反復数と分母。
- `coverage.csv`：観測ゲーム、比較投球、グループ、反復数、区間算出可否の件数。
- `checks.csv`：元集計・固定モデル・ゲーム別点推定の照合残差。
- `metadata.json`：元診断metadata、再抽出方法、入力ハッシュ、seed、仮定と制限。

summaryの`sampled_games`は共通の抽出母集団数、`contributing_games`は当該グループに比較投球がある観測ゲーム数。
`reference_searched`／`candidate_searched`、各fair、common_fairは観測値の分母である。

疎な高さ帯・戦略設定では、ある再抽出でそのグループが含まれず、率や平均の分母がゼロになる場合がある。
その反復を0に置換しない。`undefined_replicates`へ数え、1回でも未定義なら当該指標の区間を空欄にする。
定義できた反復だけの条件付き分布を、完全なbootstrap区間として表示しない。
`interval_status`と件数を確認する。未定義点推定も空欄のまま残す。

`interval_relation`は区間が正側／負側／0を含むかの表示で、p値や自動採用判断ではない。
0.6 m未満の枝が不変なら、比較可能な指標の差・区間は0になるのが期待される。

## 結果の限界と次の判断

ゲーム内の投球依存には対応するが、別ゲームに繰り返し登場する同じ選手・チームによる依存は取り除かない。
各区間は個別の区間で、多重比較補正をした同時区間ではない。
小さいグループやゲーム数の少ない結果を強い一般化の根拠にしない。
固定モデル内での安定性を確認するもので、独立holdoutや実野球との一致を確認する実験ではない。

接触率・フェア方向の割合、下向き減少、ライナー窓増加、高角度増加を高さ別に併せて評価する。
結果を見て同じ標本で狙い閾値や物理係数を調整せず、改善案を作る場合は探索と次の検証を分ける。

固定応答のRust移植と、新規記録での一致確認は[衝突応答のRust診断](rust_collision_response.md)を参照。

## 検証

```sh
python3 -m unittest discover -s tests/diagnostics -p 'test_rust_intent_game_bootstrap.py'
python3 -m unittest discover -s tests/diagnostics -p 'test_*.py'
```

不均等なゲーム投球数の分母、共通ゲーム抽出・seed再現性・グローバル乱数不変、効果ゼロ、
元集計との一致、欠落／重複ペア・フラグ・集計・コードハッシュの改変拒否、
疎な集団の未定義反復、DBなしCLI、出力非上書きを検証する。
