# 打点・衝突方向と有効質量の診断

## 目的

基準軸20/30/40°を比較しても、強い打球への集中は大きく変わらなかった。
今回は接触位置・法線・投球速度・接触点速度を固定し、打点と慣性から有効質量を求めて
衝突だけを再計算する。接触探索・本体の結果・予定軸・係数e=0.5を変更しない。

入力は前回の**観測更新診断**の出力。今回のデータは高さ依存軸の回転モデルであり、
基準軸20/30/40°を再探索する実験ではない。

## 物理的な境界条件を分ける

衝突前に支点を使ってスイング軌道を作ったことと、衝突中の支点を拘束することは別の仮定。
次を分け、握りのモデルを暗黙に混ぜない。

| mass_model | 衝突中の応答 |
|---|---|
| constant_0.6kg | 従来の一定有効質量による基準 |
| free_k...m | バットの重心が反跳し、重心周りにも回転する自由剛体 |
| pivot_k...m | 衝突前の速度で動く支点を拘束し、支点周りの回転だけが変わる剛体 |

自由剛体は、短い衝突中の握りの力を無視する近似。支点拘束は比較用の別の境界条件。
どちらが実際の打撃を適切に表すかを今回の結果だけで確定しない。

## 座標・質量・慣性の定義

- a：接触時のバット単位軸。
- n：接触法線。
- s：有限区間内の軸方向打点`closest_axial_at_entry_m`。中央0、正は軸の正方向。
- L：保存された回転モデルの支点から基準打点までの距離。バット全長ではない。
- c：基準打点から重心までの軸方向オフセット。負は支点側。
- M：診断仮定の剛体質量。従来の有効質量と概念上は別。
- k：重心周りの横方向の回転半径（radius of gyration）。`I_cm = M*k²`。

kは質量分布を要約する長さであり、バットの物理的な半径や、b/RのRではない。

```text
r_cm = (s-c) * a
r_pivot = (L+s) * a
I_cm = M * k²
I_pivot = I_cm + M * (L+c)²

inverse_effective_mass_free = 1/M + |cross(r_cm,n)|² / I_cm
inverse_effective_mass_pivot = |cross(r_pivot,n)|² / I_pivot
```

同じM/c/k/Lについて、自由剛体と支点拘束で同じ質量分布を使い、平行軸の関係を満たす。
慣性はバット長軸に直交する方向に等しいとする。接触の作用点は保存された最近接軸点で表す。
法線方向に作用点をずらしても力のモーメントは変わらず、この摩擦なしモデルでは
法線方向の応答も変わらない。長軸周りのスピン・接線力積・振動は含めない。
保存された角速度に無視できない長軸成分があれば、今回のエネルギー検証の範囲外として停止する。

**ここで使うモーメントアーム`|r×n|`は、以前の最接近距離b/Rのbとは異なる。**
前者は力の作用線と回転中心との関係、後者は球と軸の相対運動の最接近距離である。
軸に沿う距離を一律に有効質量へ入れず、衝突方向との外積で求める。

## 既定値は実測ではなく基準一致の感度仮定

M=0.6kg、c=0m、k=0.15/0.25/0.35mを既定とする。
重心を基準打点へ置くのは診断上の仮定で、実際のバットの重心を推定したものではない。
この条件では自由剛体の中央接触でMeff=M=0.6kgとなり、従来の基準と一致する。

| k | I_cm | I_pivot（L=0.9m、c=0） |
|---|---:|---:|
| 0.15m | 0.0135kg·m² | 0.4995kg·m² |
| 0.25m | 0.0375kg·m² | 0.5235kg·m² |
| 0.35m | 0.0735kg·m² | 0.5595kg·m² |

これらは実測・文献値として採用したバット仕様ではない。Contact率やEVに合わせて調整した値でもない。
`--body-mass-kg`、`--cm-offset-m`、`--gyration-radii-m`で明示的に変更できる。
変更しても従来基準のconstant_0.6kgは固定。

自由剛体では重心から外れると有効質量が小さくなる。支点拘束では支点側の打点で
有効質量が大きくなる場合もある。全モデルが一様にEVを下げると期待しない。

## 衝突と保存則の確認

逆有効質量をμ、球質量をm、接近前の法線相対速度をu_nとすると、

```text
delta_ball_speed = max(0, -(1+e)*u_n / (1+m*μ))
J = m * delta_ball_speed
v_ball_after = v_ball_before + delta_ball_speed*n
```

自由剛体では重心速度変化`-J*n/M`と角速度変化`-J*(r_cm×n)/I_cm`、
支点拘束では支点速度を変えず`-J*(r_pivot×n)/I_pivot`を計算し、法線反発則と整合させる。
自由剛体の並進力積、両剛体の角力積、反発則、エネルギー収支を検証する。
支点拘束のエネルギーは支点と同じ速度で平行移動する座標系で検証し、
拘束反力のあるモデルへ自由剛体の並進運動量保存を誤適用しない。

支点拘束でトルクが0なら逆有効質量は0、有効質量は無限大の極限になる。
大きな有限値へのクリップはせず、逆質量0の式で厳密に処理する。
CSVではeffective_mass_kgを空欄、infinite_mass_contactsへ件数を残す。
有限質量の平均と逆質量の平均を混同しない。

衝突後のバットの応答は検証用に計算する。保存された軌道をその応答で進め直す実装ではない。

## 実行

次の3ファイルがある、以前の観測更新の出力ディレクトリを指定する。

- observation_update_contacts.csv
- observation_update_metadata.json
- observation_update_coverage.csv

```sh
python3 tools/diagnostics/effective_mass_probe.py --input-dir ../saberbb_observation_update --output-dir ../saberbb_effective_mass
```

**新しい試合・DB移行・接触探索の再実行は不要。**
巨大な元CSVを削除していた場合は、同じDB・24958～25317で観測更新診断を再実行すればよい。
入力ファイルは読み取り専用。キー検査には一時SQLiteを使い、入力SHA-256を出力する。
既定は従来1＋自由剛体3＋支点拘束3の計7モデル。

## 出力・確認順

| ファイル | 用途 |
|---|---|
| effective_mass_coverage.csv | 元試行数、接触幾何の件数、モデル数と展開件数 |
| effective_mass_status.csv | 探索状態・衝突状態の件数 |
| effective_mass_checks.csv | 元の衝突再現、反発則、力積・エネルギー収支の残差 |
| effective_mass_distribution.csv | 質量帯×side/cap、無限質量・接触なしの件数 |
| effective_mass_summary.csv | 打点帯・衝突帯ごとの有効質量、EV/HLA/VLA、方向・弱い打球の割合 |
| effective_mass_pairs.csv | 同一イベントの基準→各モデルの比較、双方フェア方向のEV比較 |
| effective_mass_transitions.csv | 衝突状態とフェア/ファウル方向の前後遷移 |
| effective_mass_metadata.json | 入力ハッシュ、質量・重心・慣性と境界条件の仮定 |

全CSVのscopeはall_swingsとrecorded_batting_onlyを分ける。後者はUnrecordedBattingを除く。
2つのscopeを合算しない。stageも同じ試行の別集計なので合算しない。

- overall：全試行。
- signed_axial：符号付きsのm帯×side/cap。支点側と先端側を分ける。
- baseline_impact：元の局所|b/R|帯×法線速度比。帯分けをモデルの結果で動かさない。
- forecast_z：予測Z誤差の符号付きm帯。

非接触に接触位置・有効質量・打球速度を付けない。有効質量の平均は接触幾何のある有限質量の集合。
EV/HLA/VLAは力積正の集合。無限質量の件数・有限質量の分母を別々に表示する。
全条件で幾何の接触数は固定される。正の有限慣性で有効質量だけを変えるので接近の符号も変わらない。

**有効質量が小さくなっても、EVが必ず下がるわけではない。**
弱い力積では球が投球方向へ高速で残る場合があるため、フェア方向（|HLA|<45°）だけの
avg_fair_ev_ms、fair_ev_lt_25_pct、fair_ev_ge_40_pctも確認する。
これは方向による区分で、実際の試合の安打・アウトや最終Foulではない。
両モデルともフェア方向となった同じイベントのEVをpairsで確認し、方向を跨ぐ球はtransitionsで数える。

まず元の一定質量結果が前回を再現するか確認し、次に打点と有効質量の関係、フェア方向の弱打が
どの接触で増えるかを見る。反発係数や角度の調整と同時に行わない。
剛体の反跳だけで不足が残る場合、振動等の損失は別のモデルとして検討する。

## 理論資料と検証範囲

[Rod Cross: Bat and ball collisions](https://physics.usyd.edu.au/~cross/BAT-BALL-COLLISIONS.htm)は
自由剛体の並進・回転から`1/Meff=1/M+b²/I`を導く。
[Cross & Nathan: Performance versus moment of inertia](https://baseball.physics.illinois.edu/jwuk_jst_88_web.pdf)
では短時間の衝突で握りの力を無視する仮定と、剛体近似・振動損失の区別が説明されている。
今回の3D外積式は、接触を摩擦なしの法線方向へ射影した実装上の拡張である。
上記の既定数値はこれらの資料から測定値として引用したものではない。

解析解、従来の衝突式との一致、中央・外れた打点、平行軸の関係、capの無限質量極限、
e=0/0.5/1の保存則、フェア/ファウル方向の変化、キー重複・欠損・破損の拒否、入力不変性を検証する。

```sh
python3 -m unittest discover -s tests/diagnostics -p 'test_*.py'
python3 -m unittest discover -s tests/sql -p 'test_*.py'
```

実行後はmetadata以外の7つのCSVを添付する。
