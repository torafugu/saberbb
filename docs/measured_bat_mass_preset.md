# 文献の木製バットによる有効質量の比較

## 目的と資料

重心を基準打点へ置いた感度診断から進み、同じバットの測定値をまとめて使う。
[Kensrud, Nathan, Smith (2017), Table II, Wood行, p.505](https://baseball.physics.illinois.edu/ObliqueCollisionsWSU-AJP.pdf)
（DOI: 10.1119/1.4982793）の質量・横方向慣性・打点と重心の距離を採用する。
バット一般の代表値や、実際の選手のバットを同定した値としては扱わない。

| 量 | 論文の値 | 診断のSI値 |
|---|---:|---:|
| 質量M | 29.41 oz | 0.8337594751 kg |
| 重心まわりの横方向慣性I₀ | 2370 oz·in² | 0.04334724866 kg·m² |
| 打点から重心までの距離b | 6.8 in | 0.17272 m |

質量ozは常用オンス（1 oz=0.028349523125 kg）、1 in=0.0254 m。
I₀は長軸に直交して重心を通る軸の慣性。支点まわりの値や長軸まわりのI_zと取り違えない。

## 保存された座標への対応

保存データの軸方向基準打点s=0を、文献の打点に対応させる。
正のsは支点から先端へ向かう方向、文献の打点は重心より先端側にある、という対応を置き、
`c=-b=-0.17272 m`とする。これは保存された打点基準と測定バットを結ぶモデル上の対応であり、
保存データから実際の重心位置を測定したものではない。
絶対的な重心位置、先端からの打点距離、全長を補って推定する必要はない。

```text
k = sqrt(I₀/M) = 0.2280134036 m
r_cm = (s + 0.17272) * a
I_pivot = I₀ + M * (L - 0.17272)²
```

L=0.9 mならI_pivot=0.4843528158 kg·m²。
側面に正対する法線でs=0なら自由剛体の有効質量は約0.529773 kg。
支点側の打点ほど重心へ近づき、先端側ほど遠ざかるため、前回のc=0と異なり左右非対称になる。
ここで文献のbは軸方向の打点–重心距離であり、軌道の最接近距離b/Rのbではない。

**接触の再探索はしない。** 保存された法線・位置・速度・有限区間・半径・Lを固定し、
質量・重心・慣性だけを変える。Lは有効なスイング支点距離で、文献のバット全長・握り位置ではない。
保存された円柱と端部も実測バットの形状を再現したものではない。
文献の打点半径は1.16 in（0.029464 m）だが、今回の探索半径へ置き換えない。
この形状差はmetadataに保存された入力条件と文献値で確認できる。
e=0.5、球質量0.145 kgも従来と同じ診断仮定。論文の反発係数を採用・検証した実験ではない。
振動・摩擦・接線力積を追加しない。

## 実行

以前の観測更新診断の出力3ファイルを使う。前回の有効質量集計CSVを入力するものではない。
新しい試合やDB移行は不要。

```sh
python3 tools/diagnostics/effective_mass_probe.py \
  --input-dir ../saberbb_observation_update \
  --output-dir ../saberbb_measured_bat \
  --preset kensrud2017_wood
```

constant_0.6kg、free_kensrud2017_wood、pivot_kensrud2017_woodの3モデルを出力する。
プリセットと手入力の質量・重心・回転半径を併用すると停止する。
これにより、測定値の一部だけが上書きされて文献バットと誤認されることを防ぐ。
入力は読み取り専用で、本体の打撃処理・試合結果・乱数消費は変更しない。

出力形式・7つのCSVは[有効質量診断](contact_effective_mass.md)と同じ。
metadataには出典・表の行・元の単位・変換定数・座標対応・各モデル名を追加する。
前回と同じ入力ハッシュ・試行数・幾何接触数であることを確認する。
入力728430試行なら3モデルで2185290衝突試行となる。

まずchecksの残差とconstant_0.6kgの前回再現を確認する。
次に同じscope/variant/stageで、自由剛体の有効質量、両方フェアのEV、方向を跨ぐ件数を比較する。
基準例はall_swings・observed_sigma_0.005のL=0.9 mに対応するvariant・overall。
signed_axialでは支点側/先端側を分ける。
弱いフェア打球が不足するかは実データで判断し、振動損失の検討はこの比較の後に行う。

実行後は従来と同じ7つのCSVを添付する。metadataも残し、使用プリセットと入力ハッシュを追跡できるようにする。
